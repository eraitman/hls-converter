프로젝트 오너. 서버 배포·DB 반영 등 되돌리기 어려운 실행은 본인이 직접 한다.

- **두 기기**에서 작업한다 → 세션 간 맥락은 저장소 안(`.claude/memory/`)에 둬야 공유된다.
- 진행 상황을 **하나씩 보고**하고, 본인이 실행할 차례를 **명시**해 주길 원한다.
- 브라우저 자동화는 이 환경에서 연결되지 않으니 쓰지 말 것.

**How to apply:** 작업 끝에 "사장님 차례" 섹션으로 오너가 실행할 명령을 정리해 준다.
긴 작업은 중간중간 결과를 보여주고, 확인이 필요한 결정은 근거와 함께 선택지를 준다.
검증할 때 로컬 DB를 띄우지 말 것 — 토큰이 많이 든다. 순수 함수 단위 테스트 + 검증 API를 쓴다.
