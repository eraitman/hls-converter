"마무리하자"라고 하면 메모리를 git으로 공유해 다른 기기에서도 알 수 있게 정리하고 커밋한다.

**Why:** 기본 메모리 경로(`~/.claude/projects/.../memory/`)는 기기에 묶여 있어
다른 작업 기기에서는 보이지 않는다. 저장소 안에 두어야 공유된다.

**How to apply:** "마무리하자"를 들으면
1. `.claude/memory/`의 메모리 파일들을 이번 세션에서 알게 된 내용으로 갱신
   (새 파일 추가 / 틀린 내용 수정 / 더 이상 사실이 아닌 것 삭제)
2. `.claude/memory/MEMORY.md` 색인도 같이 갱신
3. 커밋·푸시하고, 무엇을 남겼는지 오너에게 요약 보고

저장 기준은 평소와 같다 — **코드·git 이력·문서를 보면 알 수 있는 것은 남기지 않는다.**
환경 특성, 오너 작업 방식, 겪은 사고와 교훈, 데이터의 함정처럼 **다시 알아내기 비싼 것**만 남긴다.
