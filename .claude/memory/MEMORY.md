# hls-converter 공유 메모리

기기 간 공유를 위해 저장소 안에 둔다 (기본 메모리 경로는 기기에 묶여 있어 다른 곳에서 안 보임).
**세션 시작 시 이 색인을 읽고, 관련 있는 항목만 펼쳐 본다.**
갱신은 "마무리하자" 요청 시 — [[wrapup-routine]] 참고.

저장 기준: **코드·git 이력·문서를 보면 알 수 있는 것은 남기지 않는다.**
환경 특성, 오너 작업 방식, 겪은 사고와 교훈, 데이터의 함정처럼 **다시 알아내기 비싼 것**만 남긴다.

- [작업 방식](user-workflow.md) — 두 기기 사용, 단계별 보고와 "내 차례" 신호를 원함
- [마무리 루틴](wrapup-routine.md) — "마무리하자" = 이 메모리 갱신 후 커밋
- [오너 결정사항](owner-decisions.md) — 인코더 혼합, ffmpeg PATH 우선, 설치 방식, 커밋 타이밍, 검증 상태
